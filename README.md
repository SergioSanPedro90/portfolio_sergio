# 💼 Portfolio · Sergio San Pedro Álvarez

Portfolio personal donde muestro mis proyectos, stack tecnológico y experiencia como desarrollador Full Stack.

## 🚀 Demo en vivo

[Ver portfolio](https://sergiosanpedro-portfolio.netlify.app/)

## 🛠️ Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Netlify (deploy)

## ✨ Secciones

- Sobre mí
- Experiencia
- Proyectos destacados
- Tecnologías y herramientas
- Contacto

## 📜 Scripts

```bash
npm install      # instalar dependencias
npm run dev      # servidor de desarrollo
npm run build    # comprobación de tipos y build de producción
npm run lint     # ESLint
npm run preview  # previsualizar el build
```
